搭建博客并不需要复杂的工具链，一个清晰的页面结构、一套统一的样式系统、再加一点恰到好处的交互，就能得到一个既美观又实用的站点。

## 一、整体规划

首先确定页面构成：首页（Hero + 置顶文章 + 文章列表 + 关于）、文章详情页。移动端优先，使用 CSS 变量统一管理颜色与间距，方便后续扩展主题。

## 二、样式系统

使用 CSS 自定义属性定义亮 / 暗两套配色，切换主题时只需替换 `data-theme` 属性，过渡自然且无闪烁。

```css
:root {
  --bg: #fafafa;
  --text: #1a1a1a;
}
[data-theme="dark"] {
  --bg: #111318;
  --text: #e6e6e6;
}
```

## 三、交互细节

文章列表由数据渲染生成，配合前端搜索即可实现即时过滤；滚动时为导航栏添加阴影，提升层次感。细节决定质感。

## 四、总结

保持简洁、注重可读性，再逐步迭代评论、标签、归档等功能，博客就会不断成长。动手试一试吧！
